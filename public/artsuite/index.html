By invitation · Mac: macOS 14 or later, Apple silicon or Intel · Windows: Windows 10 or 11, 64-bit

Install on Mac

  1. Open the downloaded ArtSuite disk image and drag ArtSuite into Applications.
  2. Open ArtSuite. Press Install on SolidArt, SculptArt or RenderArt.
  3. ArtSuite checks for updates on its own. Each app also has Check for Updates… in its menu.

Install on Windows

  1. Unzip the download and open ArtSuite.exe. It installs itself and adds ArtSuite to the Start menu.
  2. If Windows says it protected your PC, click More info, then Run anyway.
  3. Press Install on SolidArt, SculptArt or RenderArt. RenderArt needs an NVIDIA graphics card.

The apps

  • SolidArt: parametric CAD for parts and assemblies.
  • SculptArt: sculpting for CNC reliefs, molds and bucks.
  • RenderArt: photoreal renders, turntables and animations.
